# Automatic video generation

The default screen accepts a canonical TikTok link and multiple clips before project creation. Generate saves the project, uploads sequentially, then runs the existing shared worker through retained retrieval, reference color/cut analysis, automatic sequence selection, per-slot transfer, audio, captions and publication. A persisted generation snapshot binds reference/clip hashes and saved revisions. Failed stages need explicit retry; safe checkpoints resume only when inputs/options remain unchanged. Saved custom edits require explicit replacement. Cancel/deletion signal the owned worker; publication checks the snapshot again. Prior output stays playable until successful replacement.

Sequence durations use estimated hard cuts rounded to 30 fps. Default selection avoids overlapping ranges; footage shortage blocks until more footage or explicit reuse authorization. Each slot targets its own reference interval, using the existing stable SDR transfer at **70% strength**. Unsupported transitions/effects are not recreated.

Visible caption extraction uses installed, pinned English/Arabic Tesseract assets: full-frame grayscale OCR at a 960-pixel long edge, discovery every 0.5 seconds, adaptive refinement of observed changes to 1/30 second. Bounds: 600 reads, 200 two-line/200-character cues, eight fitted appearance groups, 300 seconds, existing contained/limited subprocesses and 16 MiB temporary stages. Low-confidence material text produces an explicit blocker. Persistent edge text is heuristically excluded. Short text entirely between discovery frames can be missed; noisy OCR, logos, multiple competing regions and same-height/anchor/color style changes require review. Fonts, outline/placement and supported motion are approximations, never font identity or universal effect reconstruction. Adjacent similarly sized centered lines can form one two-line cue.

Each cue can preserve its own font/style/animation in caption schema 2. Legacy schema-1 tracks remain compatible. Manual correction is available in Customize. Reference words never come from speech transcription. Caption my audio first renders an unpublished caption-disabled scratch export using the saved sequence, color/framing and selected audio, then transcribes that actual output audio and records its hash/timeline/audio binding. No intermediate export replaces the completed output.

Capability preflight precedes retrieval/long work. Install both optional Python sets together in backend: `uv sync --locked --extra visual --extra transcription`; follow the existing OCR/model setup guides. Generation reuses installed assets and never downloads them implicitly. The overall coordinator deadline is 1,200 seconds; individual stage deadlines retain their existing limits capped by remaining time.
